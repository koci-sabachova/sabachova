# sabachova.com — osobní web Kateřiny Kočí Šabachové

## Soubory
- `index.html` + `style.css` + `script.js` — hlavní design (blob hero)
- `index-alt.html` + `style-alt.css` — alternativní design (brutalistní grid, emoji pole) — **aktivně rozvíjený**
- `kac_emoji.png` — osobní emoji avatara, použitá v emoji poli i jako favicon

## Barevná paleta
```
--paper:    #eeeeee   (světlé pozadí)
--ink:      #1b1b1f   (tmavý text, bordery)
--blue:     #041562   (tmavá modrá — hero panel, akcenty)
--blue-soft:#11468f
--red:      #da1212   (červená — CTA, čísla, zvýraznění)
--red-soft: #da1212
```

## Typografie
- Font: `-apple-system, "SF Pro Rounded", "Segoe UI Rounded", ui-rounded, ...`
- Základní velikost: `17px`
- Nadpisy: `font-weight: 800–900`

## Alt design — klíčové detaily
- Hero: 2-sloupcový grid — levý panel (modrý) s textem, pravý panel s emoji polem
- Emoji pole: vanilla JS, 45 emoji + kac_emoji.png vmíchané, náhodné pořadí při každém načtení
- Klik na kac_emoji.png → konfety (letí nahoru)
- Projekty rozděleny na **Weby** a **Appky**
- Komunikace: tykání konzistentně
